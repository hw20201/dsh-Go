# 远程主机

dsh-Go 连接电脑或服务器上的 DSH；对话、工作区和插件属于所连接的主机。当前 App 不提供手机本机引擎的安装、启动、Linux 环境、重置或卸载入口，打开 App 也不会自动启动手机本机引擎。

## 第一次打开

第一次打开 App 时，连接电脑或服务器上的 DSH，不在手机上安装引擎。

## 切换主机

打开对话列表，点底部的主机名，打开**切换主机**，选择一台已保存的远程主机。还没有主机时点**连接电脑或服务器**，已有时点**管理远程主机**。

点主机名左边的图标查看当前远程主机的连接状态和网络路径，支持时可手动测量延迟。

## 添加 SSH 主机

那台主机需要开着 SSH，并装好 DSH（`npm i -g @deepseek-ai/dsh`）。

1. 在远程主机页点**添加 SSH 主机**。
2. 填写**主机**、**用户名**，**端口**默认 22。名称可以留空。
3. 选择**密码**或**私钥**登录。私钥可以**从文件导入**，有口令时填**私钥密码（可选）**。密码和私钥只保存在这台手机上。
4. **实例管理**默认**托管启动**：**启动命令**默认 `dsh web`；用 nvm 安装的 DSH 可以填完整路径。已有自己管理的实例时选**只连接**，填写**远端 DSH 端口**和该实例启动链接中的 **DSH 登录令牌**。**工作目录（可选）**是新对话的默认目录；只连接模式请用绝对路径。
5. 点**测试连接**。首次连接会弹出**信任这台主机？**：在那台主机上核对指纹，一致再点**信任并连接**。
6. 点**保存**，再在主机列表里选中它。

托管模式的测试连接会启动或复用远端 DSH，测试结束后它继续运行。**只连接**只建立 SSH 隧道到远端 `127.0.0.1` 的指定端口，不自动查找实例，不执行启动、停止或重启，不读写托管状态文件；请先在远端启动实例并保持运行。连接失败时检查端口与令牌，App 不会用重启修复它。令牌和 SSH 密码、私钥一样，仅保存在手机安全存储中。

托管模式发现仍活着但启动命令不同、日志丢失的实例时，会明确停止连接而不是自动杀掉它；登录令牌被拒绝、复用端口拒连也不会授权重启。先检查配置或改用**只连接**；确实要替换 App 记录的实例时，在编辑主机的 DSH 区选择**重启托管 DSH**，确认后才停止并重启。此操作可能中断其他客户端和进行中的对话，普通**测试连接**不会执行它。已确认死亡的托管进程仍可自动补启。

**SSH 压缩**默认开启，协商认证后压缩；服务器不支持时保持未压缩传输。可在主机编辑页关闭，保存后重新建立 SSH 连接生效。

修改或删除：点主机右侧的**编辑**按钮，进入**编辑主机**，底部是**删除这台主机**。删除只移除手机上保存的设置、密码、私钥和登录令牌，远端的 DSH 和对话不受影响。

## DSH Remote

无需配置网络，连接端到端加密，适合不在同一网络的电脑。

1. 在那台主机的 DSH 里装好远程插件并登录。
2. 在远程主机页选择你在那台主机上使用的登录方式，例如「使用 GitHub 登录」，再用同一账号登录。如果页面没有列出登录方式，只显示**在浏览器中登录**，点它继续。
3. 在列表里选中在线的主机。首次连接时核对身份指纹，与主机上远程插件显示的一致再点**信任并连接**。

服务器支持时也可选「扫码配对电脑」：先在 App 登录 DeepSeek，再扫电脑 Remote 插件显示的配对二维码，核对电脑指纹后按提示输入验证码。相机权限只用于拍摄二维码；拒绝后仍可从相册识码或粘贴配对链接。打开扫码界面会按需初始化共用的 ML Kit SDK，不需要先开启手机操控的文字识别，也不会改变它的开关；SDK 的统计说明见[常见问题](11-faq.md#本机文字识别与-google-ml-kit)。

在远程主机页的 DSH Remote 的**连接路径** 中选择：**自动（推荐）**依次尝试局域网 / P2P、TURN、Relay；**仅 Relay 中继**跳过 WebRTC；**仅直连（LAN / P2P）**不使用 TURN 或 Relay 数据通道，失败时提示切回自动或仅 Relay。仅直连仍通过 Relay 完成账号认证和连接协商。路径选择只影响 DSH Remote，不影响独立的 SSH 或 DSH 地址直连主机；保存后在下次连接生效，已建立连接不会立刻断开。需要立即切换时，点**按新路径重新连接**，确认后当前连接和进行中的操作可能中断。网络详情分别显示当前实际路径和下次连接所选路径，并提供连接耗时、可测的往返延迟和回落原因；WebRTC 路径还显示所选 ICE 候选的手机／主机 IPv4 或 IPv6、UDP 或 TCP，不显示原始 IP。未测量或无法确认的项目不会冒充已知结果。

<!-- nav: commonSettings,commonRemoteHost,remoteCompactHistory -->
`设置 › 远程主机 › 精简历史`

**精简历史**默认关闭。开启后，支持的 DSH Remote 主机会把历史工具参数和输出转为摘要，减少历史传输量；正文、实时回复和审批不变，也不会修改主机原始记录。切换到其他远程主机后再连回来，或重启 App 后生效；当前连接及其自动重连保留原模式，避免历史缓存混用。关闭后同样需要重新选择主机，再打开对话获取完整历史。旧主机没有该能力时仍传输完整历史，SSH 不受此设置影响。

DSH Remote 一次只连一台主机，切换会断开上一台。经 DSH Remote 连接时：只能发送图片；插件只能开关；DS Bot 和导出对话日志不可用。
